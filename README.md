# 달빛맞고

한게임 신맞고의 규칙과 판 분위기를 따른 2인 맞고 웹 게임입니다. 브라우저에서 바로 AI와 두거나, 방 코드로 친구와 실시간 대전을 할 수 있습니다.

## 실행

```bash
npm install
npm test          # 규칙 엔진 단위 테스트
npm run dev       # 개발 서버 (기본 포트 47231)
```

프로덕션 빌드:

```bash
npm run build
npm start         # NODE_ENV=production, 같은 포트에서 정적 파일과 WebSocket
```

브라우저에서 `http://127.0.0.1:47231` 을 엽니다. 포트를 바꾸려면 `PORT=48000 npm start` 처럼 지정하면 됩니다.

모바일에서는 대국을 시작하는 탭과 함께 가로 전체화면을 요청합니다. 방향 잠금이 안 되는 기기(iOS Safari 등)에서 세로로 들어오면 “가로로 돌려주세요” 안내가 뜹니다. 홈 화면에 추가하면 `manifest.webmanifest` 기준으로 가로 전체화면으로 열립니다.

첫 클릭 때 배경음이 시작됩니다. 화면 위쪽에서 배경음과 효과음을 따로 끄거나 크기를 조절할 수 있습니다.

## 게임

- **혼자 두기**: 서버가 두는 AI와 바로 한 판.
- **방 만들기**: 6자리 코드와 초대 링크. 상대가 들어오면 양쪽이 준비를 누릅니다.
- **빠른 입장**: 비어 있는 방에 들어가고, 없으면 새 방을 만듭니다.
- 점당 1천·5천·1만·5만·10만 원. 시작 보유금은 100만 원이며, 상대가 가진 만큼만 오갑니다. 무료 충전은 100만 원, 10초 간격, 보유금 상한 2,000만 원, 진행 중인 판에서는 막습니다.
- 손패를 고르면 같은 달의 바닥패가 빛납니다. 내는 시간은 15초, 고/스톱·선택지는 10초이고, 두 번 놓치면 자동치기가 켜집니다.
- 첫 판의 선은 밤일낮(높은 달) 또는 랜덤. 이후에는 승자가 선이고, 나가리면 선과 배수가 유지됩니다.
- 접속이 끊기면 같은 브라우저에서 이어지고, 90초가 넘으면 기권으로 처리됩니다.
- 손패와 더미 순서는 서버만 알고, 클라이언트에는 공개된 패만 전달됩니다.

로비에서 닉네임과 캐릭터 8명 중 하나를 고릅니다. 대국 중에는 고, 뻑, 쪽, 승리 같은 상황에 맞춰 표정과 대사가 바뀌고, 이모티콘을 보낼 수 있습니다.

## 규칙 요약

화투 48장과 보너스패 2장(쌍피, 쓰리피). 각자 10장, 바닥 8장.

쪽, 뻑, 자뻑, 따닥, 판쓸이, 흔들기(두 번이면 4배), 폭탄, 총통(10점), 국진의 열끗/쌍피 전환, 고/스톱(3고부터 2·4·8·16배), 피박·광박·멍박·고박, 미션, 나가리를 계산합니다. 정산 창에서 배수가 차례로 쌓이고 돈이 올라갑니다.

자세한 설명은 로비의 **규칙** 버튼에 있습니다.
